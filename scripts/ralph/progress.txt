## Codebase Patterns
- Prisma uses `@prisma/adapter-libsql` (PrismaLibSql) - always pass adapter when constructing PrismaClient
- SQLite/LibSQL via Prisma does not support `String[]` - use `Json @default("[]")` for array fields
- Tests needing PrismaClient must use `// @vitest-environment node` and import `dotenv/config`
- Vitest global setup is jsdom - node-specific tests need per-file environment override
